# H5 网易云同步歌单与常规加歌

## API 与客户端

`GET /music-api/v1/auth/options` 可增量返回 `library.playlistAdd` 和
`library.neteasePlaylistSync`。客户端只在对应字段为 `true` 时调用新接口。
没有能力字段的运行端继续使用带 revision 的 PUT 加入普通歌单。

- `POST /playlists/sync {urlOrID}` 创建私有订阅，首次完整读取后返回 Playlist。支持网易云桌面、网页 hash、移动、客户端分享文字及能返回网易云歌单地址的 `163cn.tv` 短链。也接受十进制正整数 ID。短链请求只访问固定的网易云域名和受限短码，读取 Location 后直接解析，曲目请求始终发往服务端配置的匿名适配器。
- `POST /playlists/{id}/sync {}` 立即尝试同步当前身份的订阅。成功返回 Playlist。异常返回稳定错误码，GET 可读失败状态及上次成功快照。首次创建后可以立即手动同步。后续刷新尝试至少相隔 30 秒，另有全局并发和速率限制。
- `GET /playlists` 与 `GET /playlists/{id}` 对订阅增量返回 `kind:"sync"` 和 `sync`，含 `source`、`sourcePlaylistID`、`lastSuccessAt`、`lastAttemptAt`、可选的 `lastError` 和 `runningUntil`。普通歌单延用已有字段。
- `POST /playlists/{id}/tracks {trackIDs}` 给普通歌单置顶新增曲目。每批最多 1000 条，先去除批内重复，按提交顺序写入。返回 `playlist`、`addedIDs`、`existingIDs` 和 `overflowIDs`。达到总容量时接收本批匹配剩余容量的曲目。
- 订阅拒绝整单 PUT 和增量加歌。普通整单 PUT、从分享复制和备份导入各保留原顺序语义。分享或备份中的订阅导出为曲目快照，导回时按原有导入规则生成普通歌单。仍可独立喜欢、入队、播放和删除本地订阅。

首次和后续同步最多接收 1000 条来源曲目，每个空间最多创建 25 个活跃订阅。
网易云详情必须给出一致的 ID、公开标志、`trackCount` 和完整的 `trackIds` 数组。
同时确认 `trackCount:0` 和空数组时，保存空歌单。元数据批次每批最多 50 个 ID、并行最多 4 个批次。
曲目响应必须覆盖每个请求 ID，最终用来源位置生成快照，保留来源重复位置。
单次来源读取最多 14 秒。数据库令牌租约和条件更新保证慢任务、重复请求和删除后的任务无法提交陈旧结果。
源错误只更新尝试状态。曲目、顺序、成功时间和版本在同一个事务提交。

## 增量迁移与启动

1. 记录当前应用二进制、静态资源、配置和数据库备份的标识，准备精确候选。
2. 对目标音乐库使用当前发布流程执行下面单独的 SQL。它为歌单表新增 8 个可空字段、两个部分索引，既有歌曲和歌单顺序原样保留。建议先确认目标库，使用事务和现场锁等待限制。

   ```sh
   psql -X -v ON_ERROR_STOP=1 --single-transaction -f script/sql/20261123_music_playlist_sync.sql
   ```

   `MUSIC_MIGRATE=false` 启动时检查新增字段。容许自动迁移的隔离环境也可通过现有 `Migrate` 执行同一增量脚本。适配器继续使用既有 `MUSIC_NETEASE_URL`。
3. 先启动后端并核对 capability 与健康，再切换 H5 静态目录。专用访客创建公开订阅、检查普通加歌前后顺序、手动同步及 SDK/播放器直连。当前候选交付阶段只在回环隔离环境执行了这些操作。
4. 服务器启动即扫描到期任务，随后每 30 秒检查一次，每轮最多读取 12 个候选。首次成功后 24 小时起具有自动同步资格，后续自动尝试后顺延约 24 小时。手动触发独立于自动日程。日志只有成功和失败计数，拉取和租约持久化不依赖网页或另一个计划任务。

## 回退

- 关闭同步功能可将 `MUSIC_PLAYLIST_SYNC=false` 并按发布流程重启当前后端。旧快照仍可读取，编辑保护仍生效，普通加歌可继续使用。静态入口也可按照线上发布流程切回此前已核准的 index 和资产。
- 如必须回滚到旧 Go 二进制，先停止新后端写入，在事务中备份并软隐藏当前活跃订阅的精确 ID，确认范围后再切换旧二进制和前端。旧后端不理解订阅字段与只读约束。软隐藏仅更新上述 ID 对应歌单的 `deleted` 和 `revision`。保留增量字段、快照、其他歌单、喜欢和队列。重新启用新后端后，按同一份记录恢复这些订阅并复核状态。已明确由用户删除的订阅不属于该恢复范围。
- 迁移可以保留在库中。不要在回退应用的同时删列或删歌单数据。

## 独立 Node/Postgres 运行端

[YesPlayMusic #6](https://github.com/kevinmatthe/YesPlayMusic/pull/6) 接独立数据库。该环境在完成对应存储和路由前省略两项能力标志。未来实现应使用云端受信任的匿名网易曲库、同语义的增量迁移与事务、来源白名单、共享数据库租约及独立音频直连。只有完成云端验证才开启标志。当前 H5 的后端及调度进程不作为云端依赖。

云端可以用一个经过鉴权的日触发入口按分页、租约及函数时限处理到期订阅。Hobby Cron Jobs
[每个任务每天最多触发一次，小时级触发精度](https://vercel.com/docs/schedules/cron-jobs/usage-and-pricing)。
单次调用超出函数执行时限的工作通过云端自身队列或有界任务分配继续。手动同步仍由用户请求立即启动。
